# No frontmatter

Notes have no YAML frontmatter. The title is the first `#` heading, tags are inline `#tag`, and todo metadata (due date, recurrence) goes inline on the checkbox line. App-only state, such as pins and view state, lives in workspace JSON. Frontmatter hides a second format inside every file and confuses people reading the raw markdown. Inline syntax keeps a note readable as plain text and easy for agents to edit.
