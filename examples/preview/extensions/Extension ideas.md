# Extension ideas

Everything past the core is an extension: the command bar's providers, History, Todos, Calendar, Contacts and Uploads already are. A workspace extension is a folder, `.common-ink/extensions/<id>/`, with an `extension.json` saying what it adds and its code (see `docs/extensions.md`). Word count, in the Catalog at the bottom of the Extensions view, is one.

Ideas for more, each a few lines:

- A "random note" command
- A view of notes that link here
- A command bar provider for headings, with `#` as its prefix
