# Plugin ideas

Built-in features are plugins: the command bar's providers and the history panel already are. A workspace plugin is two files, `.common-ink/plugins/<id>/plugin.json` and `index.js`, on the same API (see `docs/plugins.md`). Word count, in this Preview, is one.

Ideas for more, each a few lines:

- A "random note" command
- A panel of notes that link here
- A command bar provider for headings, with `#` as its prefix
