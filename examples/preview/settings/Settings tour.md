# Settings tour

Settings are JSON files, and the settings editor (⌘,) is a view of them. A change in the editor writes just that one key, as an ordinary change you can see in history and undo.

- User settings are yours, in every workspace.
- Workspace settings are this workspace's, and win over yours.
- The defaults are read-only.

A few to try:

- Line numbers
- Font size 18
- `"keybindings": [{"key": "Mod-k", "command": "quickOpen"}]` in the JSON
